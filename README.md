# Modern Portfolio - Livish Kumar

A high-performance, responsive personal portfolio website built with modern web technologies. This project showcases the professional profile, skills, and projects of **Livish Kumar**, a Backend Software Engineer.

## 🚀 Technologies Used

- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite 7](https://vitejs.dev/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Deployment**: Configured for single-file bundling via `vite-plugin-singlefile`.

## ✨ Features

- **Responsive Design**: Fully optimized for mobile, tablet, and desktop screens.
- **Dark/Light Mode**: User preference is saved via `localStorage` for a consistent experience across sessions.
- **Interactive Sidebar**: Smooth navigation with active section highlighting.
- **Micro-animations**: Subtle entrance animations and hover effects using Framer Motion.
- **Single Page Application (SPA)**: Smooth smooth scrolling between sections.
- **Comprehensive Sections**:
    - **Home**: Introducing the professional profile.
    - **About**: Detailed summary of expertise and personality.
    - **Resume**: Professional experience, education, and technical skills.
    - **Portfolio**: Showcase of major projects with key highlights.
    - **Contact**: Easy-to-use contact form and social links.

## 🛠️ Project Structure

```bash
src/
├── components/       # UI Components (Home, About, Resume, Portfolio, Contact, Sidebar)
├── data.ts           # Centralized configuration for all portfolio content
├── App.tsx           # Main application logic and routing
├── index.css         # Global styles and Tailwind directives
├── main.tsx          # Application entry point
└── utils/            # Helper functions and utilities
```

## ⚙️ Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```bash
   cd build-portfolio-from-resume
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

### Development

Start the development server:
```bash
npm run dev
```

### Build

Create a production-ready bundle:
```bash
npm run build
```

The output will be generated in the `dist/` directory.
